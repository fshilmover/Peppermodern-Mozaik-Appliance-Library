MOZAIK LIBRARY · INSTALL GUIDE

Installing the appliance & fixture library

One folder holds the whole library — 36 products with their category tree, spec-sheet dimensions, and 3D models. Installing it is a copy and a restart.

Nothing here touches your existing libraries. You can also pull single products into a library you already have — that's covered below.

01 · What you're installing

A Mozaik product library is a folder. This one looks like this:

PM Fixtures and Appliances\ ├── Library.ndx the category tree Mozaik shows in the browser ├── parameters.dat standard library parameters └── Products\ ├── Wolf CSO24TE Steam Oven.moz the product (dimensions, settings) ├── Wolf CSO24TE Steam Oven.skp its 3D model — always beside its .moz └── … 35 more pairs

Every product is fixed-size: the width, height, and depth from the manufacturer's spec sheet are stored in the file and can't be stretched in a job. There is nothing to configure after installing.

The repository also carries a specs folder — the manufacturer's spec sheet for every product, named to match it — for your submittal product-data sections. It's not part of the Mozaik install; grab PDFs from it as you need them.

02 · Get the files
Download the latest release zip — no GitHub account needed

Two other ways to the same files: on the repository page, the green Code button → Download ZIP; or, if you use git, git clone the repository and git pull whenever you want updates.

03 · Install the whole library
  1. Unzip the download somewhere convenient and find the folder PM Fixtures and Appliances (in the release zip it's at the top; in the repo zip it's inside Product Libraries).
  2. Close Mozaik.
  3. Find your Mozaik Product Libraries folder. On a default install that's C:\Mozaik\Product Libraries — it's the folder that already contains libraries like Appliances V12. If your shop keeps Mozaik data somewhere else, it's wherever those library folders live.
  4. Copy PM Fixtures and Appliances into it — the whole folder, not just its contents.
  5. Open Mozaik. Under Libraries → Products you'll see PM Fixtures and Appliances with its categories: Sinks, Ovens, Refrigeration, Faucets, and the rest. Mozaik finds libraries by scanning that folder at startup, so the restart is what makes it appear.
04 · Verify it

Place Wolf CSO24TE Steam Oven (under Ovens) in a scratch job and check three things:

  1. It faces the room and looks like a steam oven — control band with knobs on top, tubular handle across the door, nothing squashed.
  2. Its dimensions read 597 × 454 × 582 mm (23-1/2" × 17-7/8" × 22-15/16") and won't stretch.
  3. It shows up in plan, elevation, and 3D.

If all three pass, the library is installed correctly — every product works the same way.

05 · Single products into your own library

You don't have to adopt the whole library. To pull one product into a library you already have:

  1. Copy the product's .moz and its matching .skp from our Products folder into your library's Products folder. The two files stay together — the .moz refers to the .skp by name.
  2. In Mozaik, open your library under Libraries → Products.
  3. Right-click the category you want it in → Add → type exactly the same name as the .moz file, without the extension. Mozaik connects the name to the file and its model.
THE NAME IS THE LINK

Mozaik binds the browser entry to the file by name. Wolf CSO24TE Steam Oven typed exactly connects to Wolf CSO24TE Steam Oven.moz; any difference creates a new blank product instead. This is Mozaik's own documented mechanism — see Copying Products to Different Library in the Mozaik knowledge base.

No dimensions or settings to enter during any of this — everything rides in the .moz.

06 · Updating

Download the newest release and replace your PM Fixtures and Appliances folder (Mozaik closed, same as the install). One caution: replacing the folder discards anything you added inside it — keep your own products in your own libraries and cherry-pick ours, and updates stay a clean swap.

07 · If something looks wrong
SymptomCause and fix
Library doesn't appear Mozaik scans for libraries at startup — close and reopen it. Then check the folder landed inside Product Libraries itself, not nested one level deeper.
Product added to your own library shows as a blank box The typed name doesn't exactly match the .moz filename. Delete the entry and re-add with the exact name.
Product places but has no 3D model The .skp isn't beside its .moz. Copy both files into the same Products folder.
Anything else Open an issue on the library's GitHub page with your Mozaik version and what you saw. That reaches us at Peppermodern — it is not a Mozaik support ticket, and Mozaik support doesn't cover this library.
